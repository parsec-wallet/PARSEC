Name desk

The ar.io names for the PYTHAI suite. Anyone can see what each name serves — that part is public. Changing one needs PARSEC, which states the change in plain words and signs it with your vault key.

Looking for PARSEC…
Reads come from ar.io gateways over HTTPS and need no wallet. Writes go to PARSEC on 127.0.0.1:9876; this page never holds a key and never builds a transaction — it asks for a named operation and PARSEC decides what that means.
