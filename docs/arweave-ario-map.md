# Arweave & ar.io — the complete source map

> Every place Parsec touches Arweave, AO, ar.io, ArNS or the sovereign name
> registries: in this tree, in the AO processes it deploys, in the upstream code
> it depends on, and in the reference corpus behind it.
> **Kept honest by** `python3 scripts/arweave-map.py` — it re-counts the tree and
> **names any file that talks about the permaweb and is not on this map.**
> `--check` exits non-zero when the map is stale. Last verified 2026-09-02.

This is a map, not a tutorial. For *how* a piece works, follow the link in the
last column: [`chains/arweave.md`](./chains/arweave.md) for the chain pack,
[`bankon-names.md`](./bankon-names.md) for the BNR,

```
                  └────────┬────────┘     └────────┬──────────────────┘
                           │                       │
  transport            ┌───┴───────────────────────┴───┐
                       │ arweave/ao.ts   (MU · SU · CU) │
                       │ arweave/ans104.ts (DataItems)  │
                       │ arweave/tx.ts · client.ts      │
                       │ permaweb/bridge/* (Base RPC)   │
                       └───────────────┬───────────────┘
                                       │
  keys & signing       ┌───────────────┴───────────────────────────────┐
                       │ src-tauri/src/chain_ar/  RSA-4096 · RSA-PSS   │
                       │ arweave/seed.ts · derive-worker.ts · jwk.ts   │
                       │ solana/kit-signer.ts (Solana-era ar.io writes)│
                       └───────────────────────────────────────────────┘
```

Two eras run side by side, and that is the single most confusing thing about
this surface: ar.io's registry moved from AO to Solana, so **`arweave/ario.ts` +
`namespaces/arns.ts` (AO) and `permaweb/` + `namespaces/solana-arns.ts` (Solana)
are both live**, with different signing keys — `arweave-hd` for the AO era,
`solana` for the Solana era (`NamespaceAdapter.addressChain`).

## 13. Known gaps in the map's territory

Stated here so the map is not read as a health certificate:

- **Two eras, one UI.** AO-era and Solana-era ArNS adapters are both registered.
  The AO-era one signs with `arweave-hd`, the Solana-era one with `solana`. Any
  work here must read `NamespaceAdapter.addressChain` rather than assume.
- **`permaweb-deploy` is pinned two majors behind** and the deploy script passes
  flags that upstream has removed. Tracked in `integration/ario-deploy.md`.
- **v1 payment proofs are attestations**, not verified reads, on both the BNR and
  the BMR. The oracle work is v2 — see `integration/toon-naming-x402.md` §3.
- **ArNS pricing is not yet audited for float arithmetic** —
  [`cypherpunk4096.md`](./cypherpunk4096.md) commitment IV still lists it.
- **Paid uploads stop at 402** unless the Arweave address already holds Turbo credits; buying credits is not in the wallet.
- **Test coverage is thin at the edges.** `arweave/` has three test files
  (`ans104`, `seed`, `tx`); `ario.ts`, `ant.ts`, `inject.ts` and both AO process
  clients have none.
